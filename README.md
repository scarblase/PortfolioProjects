🚀 **Data Analytics & Business Intelligence Portfolio** 📊

Welcome to my **PortfolioProjects** repository! This collection showcases my expertise in **SQL, Python, and data visualization** through hands-on projects that analyze real-world datasets. From **data cleaning** to **exploratory data analysis (EDA)** and **business insights**, these projects reflect practical applications of data-driven decision-making. 💡

---

## 🔍 **Project Highlights**

### 📈 **COVID-19 Data Analysis**
- **Tools:** SQL, Excel, Tableau
- **Goal:** Analyze COVID-19 trends in cases, deaths, and vaccinations.
- **Key Insights:**
  - Identified global trends in infection and vaccination rates.
  - Analyzed country-wise impact using SQL queries and Tableau visualizations.
- **Files:** `Covid Portfolio Project.sql`, `CovidDeaths.xlsx`, `CovidVaccinations.xlsx`

### 🏡 **Nashville Housing Market Data Cleaning**
- **Tools:** SQL
- **Goal:** Prepare messy real estate data for analysis.
- **Key Steps:**
  - Standardized date formats and address fields.
  - Removed duplicates and handled missing data.
- **File:** `NashvilleHousingPP(Data Cleaning).sql`

### 💰 **Billionaires Dataset Analysis**
- **Tools:** Python (Pandas, Matplotlib, Seaborn)
- **Goal:** Examine wealth distribution and industry dominance.
- **Key Insights:**
  - Tech industry dominates billionaire wealth.
  - Identified top wealth-generating countries.
- **File:** `Billioners Dataset.xlsx`

### 🎬 **Netflix Customer Database Exploration**
- **Tools:** Python (Pandas, Seaborn)
- **Goal:** Understand customer viewing habits and trends.
- **Key Findings:**
  - Analyzed genre preferences and subscription patterns.
  - Explored customer retention rates.
- **File:** `Netflix Customer Database Exploration.ipynb`

### 🛒 **Bike Store Sales Performance (Excel Dashboard)**
- **Tools:** Excel (Pivot Tables, Charts)
- **Goal:** Build an interactive sales performance dashboard.
- **Key Insights:**
  - Identified best-selling products and peak sales periods.
  - Analyzed regional sales trends.
- **File:** `Excel Project Bike Store.xlsx`
